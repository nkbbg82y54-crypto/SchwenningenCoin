In fünf Schritten zu deiner Solana-Adresse. Für den Empfang unserer kostenlosen Token musst du keine Kryptowährung kaufen.

Schritt für Schritt

  1. Phantom herunterladen

    Wähle den Store für dein Smartphone und installiere Phantom. Für die Browser-Erweiterung öffne die Phantom-Website.

    Für deinen DesktopPhantom

  2. Neue Wallet erstellen

    Öffne Phantom und wähle „Create a New Wallet“. Diese Anleitung nutzt „Create a Recovery Phrase Wallet“, also eine Wallet mit Wiederherstellungsphrase. Folge den Schritten für Passwort beziehungsweise biometrische Entsperrung.

  3. Wiederherstellungsphrase sichern

    Schreibe die zwölf Wörter in der angezeigten Reihenfolge auf und bewahre sie sicher offline auf. Gib sie niemals weiter. Schließe die Einrichtung ab; Passwort oder Face ID ersetzen diese Sicherung nicht.

  4. Solana-Adresse kopieren

    Am Smartphone: Tippe unten rechts auf „+“, dann auf „Receive“ (Empfangen). Unter „Tokens“ kopierst du die Solana-Adresse.

    Im Browser: Öffne „Receive“ auf der Startansicht und kopiere die Adresse für Solana.

  5. Schwenningen Token anfragen

    Sende uns deinen Namen, deinen Bezug zu Schwenningen und deine kopierte öffentliche Solana-Adresse.

    Token per E-Mail anfragen →
Nur deine öffentliche Adresse teilen.

Wir fragen niemals nach deiner Wiederherstellungsphrase, privaten Schlüsseln oder Passwörtern.

Begriffe: Blockchain, Solana und Wallet

Wichtige Begriffe einfach erklärt

Wer neu in der Welt von Wallets, Solana und Tokens ist, muss nicht alles sofort technisch verstehen. Diese Übersicht erklärt die wichtigsten Begriffe rund um den Schwenningen Token einfach und ohne Fachsprache.

🔗

Blockchain

Eine Blockchain ist ein öffentliches digitales Netzwerk. Man kann sie sich wie ein gemeinsames digitales Kassenbuch vorstellen, das von vielen Computern gleichzeitig gespeichert und geprüft wird.

⚡

Solana

Solana ist die Blockchain, auf der der Schwenningen Token läuft. Sie ermöglicht schnelle Transaktionen und geringe Netzwerkgebühren.

🪙

Token

Ein Token ist ein digitales Objekt auf einer Blockchain. Der Schwenningen Token ist als lokales Community- und Sammlerprojekt gedacht.

👛

Wallet

Eine Wallet ist deine digitale Brieftasche. Dort kannst du SOL, den Schwenningen Token und andere Solana-Token empfangen und anzeigen.

📬

Öffentliche Adresse

Die öffentliche Adresse darfst du weitergeben. An diese Adresse können Tokens gesendet werden. Sie ist nicht dein Passwort.

🔐

Seed Phrase

Die Seed Phrase ist der geheime Wiederherstellungsschlüssel deiner Wallet. Wer sie kennt, kann deine Wallet kontrollieren. Niemals weitergeben.

💵

SOL

SOL ist die Kryptowährung des Solana-Netzwerks. Sie wird für Netzwerkgebühren benötigt, wenn man selbst Transaktionen ausführt.

🔍

Explorer

Ein Explorer wie Solscan ist eine öffentliche Suchmaschine für Blockchain-Daten. Dort kann man Token, Adressen und Transaktionen prüfen.

🧩

SPL-Token

SPL ist der Token-Standard auf Solana. Dadurch können Wallets und Explorer Solana-Token erkennen und anzeigen.

🏦

Kryptobörse

Eine Kryptobörse ist ein Anbieter, über den Kryptowährungen wie SOL gekauft werden können. Danach können sie an die eigene Wallet gesendet werden.

Merksatz:
Die Blockchain ist das öffentliche Netzwerk. Solana ist die technische Plattform. Phantom ist deine Wallet. Deine öffentliche Adresse darfst du teilen. Die Seed Phrase bleibt immer geheim.
Warum verwendet das Projekt eine Blockchain?

Warum Blockchain?

Eine Blockchain macht digitale Vorgänge öffentlich nachvollziehbar. Beim Schwenningen Token bedeutet das: Tokenmenge, Transfers und Token-Adresse können transparent über öffentliche Explorer geprüft werden.

Solana wurde gewählt, weil Transaktionen schnell und mit sehr geringen Netzwerkgebühren möglich sind.

Transparent: Token und Transaktionen sind öffentlich überprüfbar.
Dezentral: Die Daten liegen nicht nur auf einem einzelnen Server.
Praktisch: Eine öffentliche Wallet-Adresse reicht aus, um Tokens zu empfangen.
