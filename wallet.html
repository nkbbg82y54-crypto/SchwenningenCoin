SCHWENNINGEN TOKEN AUF SOLANA

Blockchain einfach erklärt

Der Schwenningen Token ist ein digitales Heimatprojekt auf der Solana-Blockchain. Hier wird einfach erklärt, was Blockchain, Solana, Tokens und Wallets eigentlich sind.

Was ist eine Blockchain?

Eine Blockchain ist ein öffentliches digitales Netzwerk. Dort können Informationen dauerhaft gespeichert und weltweit geprüft werden.

Die bewegten Lichtpunkte symbolisieren Daten, die weltweit über die Blockchain übertragen werden.

Was ist Solana?

Solana ist die technische Plattform hinter dem Schwenningen Token. Sie ermöglicht schnelle und günstige digitale Transaktionen.

Was ist ein Token?

Ein Token ist ein digitaler Wert oder Nachweis auf einer Blockchain. Der Schwenningen Token soll regionale Verbundenheit digital sichtbar machen.
