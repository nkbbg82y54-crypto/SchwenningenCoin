SCHWENNINGEN TOKEN AUF SOLANA

Blockchain einfach erklärt

Der Schwenningen Token ist ein digitales Heimatprojekt auf der Solana-Blockchain. Hier wird einfach erklärt, was Blockchain, Solana, Tokens und Wallets eigentlich sind.

Was ist eine Blockchain?

Eine Blockchain ist ein öffentliches digitales Netzwerk. Man kann sie sich wie ein gemeinsames digitales Kassenbuch vorstellen.

Dieses Kassenbuch liegt nicht nur auf einem einzelnen Computer, sondern wird von vielen Computern gleichzeitig gespeichert und geprüft. Dadurch können Einträge nicht einfach heimlich verändert werden.

Wenn ein Token übertragen wird, entsteht ein neuer Eintrag. Dieser Eintrag wird dauerhaft gespeichert und kann später öffentlich überprüft werden.

Öffentlich: Jeder kann prüfen, dass der Token existiert.
Dauerhaft: Einträge bleiben auf der Blockchain nachvollziehbar.
Transparent: Tokenmenge und Tokenkonten sind sichtbar.
Nicht zentral: Die Daten liegen nicht nur bei einer einzelnen Stelle.

Was ist Solana?

Solana ist die Blockchain, auf der der Schwenningen Token läuft. Man kann sich Solana als technische Grundlage vorstellen: Sie sorgt dafür, dass der Token existiert, verschickt werden kann und öffentlich überprüfbar bleibt.

Der Schwenningen Token ist ein sogenannter SPL-Token. SPL ist der Token-Standard auf Solana — ähnlich wie ein gemeinsames technisches Format, damit Wallets und Explorer den Token erkennen und anzeigen können.

Schnelle Transaktionen

Solana ist auf schnelle Übertragungen ausgelegt. Wenn ein Token verschickt wird, erscheint die Transaktion in der Regel sehr schnell auf der Blockchain.

Geringe Gebühren

Für Transfers auf Solana fallen üblicherweise nur sehr kleine Netzwerkgebühren an. Das macht Solana für Community-Projekte besonders geeignet.

Öffentlich prüfbar

Über Dienste wie Solscan oder den Solana Explorer kann jeder sehen, dass der Token existiert und welche Tokenkonten ihn halten.

Keine zentrale Website nötig

Die Website erklärt das Projekt. Der Token selbst liegt jedoch auf der Solana-Blockchain und ist dort unabhängig öffentlich sichtbar.

Einfach gesagt:
Solana ist die technische Straße. Die Wallet ist deine digitale Brieftasche. Der Schwenningen Token ist das digitale Objekt, das auf dieser Straße übertragen werden kann.

Was ist ein Token?

Ein Token ist ein digitales Objekt auf einer Blockchain. Er kann in einer Wallet gespeichert, von einer Adresse zu einer anderen übertragen und öffentlich über die Blockchain geprüft werden.

Der Schwenningen Token ist kein Geldversprechen, keine Aktie und kein Investmentprodukt. Er ist als lokales Community- und Sammlerprojekt gedacht: ein digitales Symbol für Heimat, Zusammenhalt und regionale Verbundenheit.

Tokenmenge: Es gibt insgesamt 165.000 Schwenningen Tokens. Die Menge orientiert sich symbolisch an etwa 1.650 Einwohnern × 100 Tokens.
Transferierbar: Der Token kann technisch von einer Solana-Adresse an eine andere gesendet werden.
Öffentlich sichtbar: Tokenadresse, Tokenkonten und Transaktionen können über Blockchain-Explorer geprüft werden.
Kein Investment: Der Token wird nicht als Geldanlage beworben und enthält kein Gewinnversprechen.

Die wichtigsten Begriffe kurz erklärt

Wallet: Deine digitale Brieftasche für Token.
Öffentliche Adresse: Eine Adresse, an die Token gesendet werden können. Diese darf weitergegeben werden.
Seed Phrase: Geheimer Wiederherstellungsschlüssel deiner Wallet. Diese niemals weitergeben.
Explorer: Eine Website wie Solscan, auf der Blockchain-Daten öffentlich geprüft werden können.
SPL-Token: Der technische Token-Standard auf Solana.
